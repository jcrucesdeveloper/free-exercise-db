# Images added for WTX

`exercises/WTX_*/0.webp` are not from upstream free-exercise-db. They are for
the exercises WTX adds on top of the catalog (warm-ups, sports, treadmill), taken
from Wikimedia Commons, each public domain or CC0, chosen so no identifiable
person is shown, then resized to 480px and re-encoded to WebP (quality 80) the
same way as `scripts/optimize-images.sh`. Only frame 0 exists.
